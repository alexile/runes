# Graph

Embedded property graph, Gremlin-style traversal and pattern matching.

| Crate | Description |
| --- | --- |
| [`rune-graph`](rune-graph) | Embedded directed property graph: nodes, edges, labels, key-value properties, traversal, algorithms, and optional snapshot persistence |
| [`rune-graph-gremlin`](rune-graph-gremlin) | Gremlin-inspired graph traversal engine for rune-graph: typed step pipeline, predicates, repeat, path tracking |
| [`rune-graph-match`](rune-graph-match) | Pattern matching engine for rune-graph: filter (node, edge, node) triples by label, property, or node id |
