# ML

Unsupervised ML: clustering, dimensionality reduction, graph embeddings, community detection.

| Crate | Description |
| --- | --- |
| [`rune-hdbscan`](rune-hdbscan) | HDBSCAN clustering — hierarchical density-based clustering with automatic noise detection |
| [`rune-kmeans`](rune-kmeans) | K-Means++ clustering — partition points into k clusters with smart initialisation |
| [`rune-labelprop`](rune-labelprop) | Label propagation — semi-supervised node classification via iterative neighbourhood smoothing |
| [`rune-leiden`](rune-leiden) | Leiden community detection — find densely-connected clusters in weighted graphs |
| [`rune-ml-core`](rune-ml-core) | Shared ML core: row-major matrices, distance metrics, deterministic RNG and estimator traits |
| [`rune-node2vec`](rune-node2vec) | Node2Vec — graph node embeddings via biased random walks and skip-gram |
| [`rune-pagerank`](rune-pagerank) | PageRank — score graph nodes by importance via random-walk convergence |
| [`rune-pca`](rune-pca) | Principal component analysis — exact (eigen / Jacobi SVD) and randomized SVD, whitening, inverse transform |
| [`rune-tsne`](rune-tsne) | t-SNE dimensionality reduction — map high-dimensional data into 2D or 3D for visualisation |
| [`rune-umap`](rune-umap) | UMAP dimensionality reduction — project high-dimensional data into 2D or nD embeddings |
