# Time series

Time series: statistics, smoothing, resampling, change points, forecasting.

| Crate | Description |
| --- | --- |
| [`rune-bin`](rune-bin) | Fixed and adaptive histogram binning for numeric distributions |
| [`rune-changepoint`](rune-changepoint) | Change-point detection: PELT and binary segmentation over L2, normal and Poisson costs, CUSUM, and Bayesian online detection |
| [`rune-correlate`](rune-correlate) | Cross-correlation and lag detection between two numeric series |
| [`rune-derivative`](rune-derivative) | Rate-of-change (derivative) and cumulative (integral) calculation over a series |
| [`rune-ewma`](rune-ewma) | Exponentially weighted moving average over a numeric stream |
| [`rune-forecast-ses`](rune-forecast-ses) | Exponential smoothing forecasts: SES, Holt, damped trend and Holt-Winters with fitted parameters, prediction intervals and AICc model selection |
| [`rune-gap-detect`](rune-gap-detect) | Detect missing/gap intervals in an expected-cadence timestamped series |
| [`rune-interpolate`](rune-interpolate) | Linear and spline interpolation for gap-filling irregular series |
| [`rune-kalman-1d`](rune-kalman-1d) | 1D Kalman filter for smoothing a single noisy scalar signal |
| [`rune-lowpass`](rune-lowpass) | Low-pass/high-pass digital filter for noisy scalar signals |
| [`rune-lttb`](rune-lttb) | Largest-Triangle-Three-Buckets downsampling for chart-ready series |
| [`rune-quantity`](rune-quantity) | Typed physical-quantity/unit system with compile-time-checked conversions (distance, speed, energy, etc.) |
| [`rune-resample`](rune-resample) | Resample an irregular timestamped series to a fixed interval |
| [`rune-season-decomp`](rune-season-decomp) | Seasonal-trend decomposition: classical additive/multiplicative, STL and MSTL |
| [`rune-stats`](rune-stats) | Nonparametric statistics: robust descriptives, rank tests and effect sizes |
| [`rune-tdigest`](rune-tdigest) | Streaming quantile/percentile estimator (t-digest-style) for large or unbounded series |
| [`rune-zscore`](rune-zscore) | Z-score and IQR-based outlier/anomaly detector |
